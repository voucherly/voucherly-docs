# Panoramica

Voucherly offre un ambiente di pagamento preconfigurato e ottimizzato che consente ai merchant di accettare pagamenti online in modo sicuro e senza sforzo, inclusi i buoni pasto, attraverso un'ampia gamma di gateway di pagamento.

Con Voucherly, i merchant non devono più integrare singolarmente ogni gateway di pagamento sui propri siti web. Voucherly si occupa di tutta la gestione.

I clienti vengono reindirizzati alla pagina di Checkout di Voucherly, dove possono scegliere tra diverse opzioni di pagamento, inclusi i gateway per i buoni pasto, e completare la transazione in modo rapido e sicuro. Per un elenco completo dei gateway di pagamento supportati, consulta [qui](resources/payment-gateways#full-list-of-available-payment-gateways).

Questa documentazione è pensata per gli sviluppatori che desiderano integrare Voucherly sul sito web di un merchant.
