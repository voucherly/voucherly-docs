# Concetti e termini
In this section, you can find terms and concepts used in Voucherly, so that you can better understand the documentation and functionality of the system itself.

## Concepts and Terms List

### ◼️ Merchant
It's the business owner of the online shop that intends to integrate Voucherly. It' the entity to which invoices will be addressed.

### ◼️ User
It's a person, typically an employee of the merchant, who has the ability to access and administrate merchant account via the Dashboard, consult the data, change the configuration, and execute operations.

One user may have access to several merchants.

### ◼️ Customer
Is the person who makes purchases on the merchant website and pays through Voucherly.

In Voucherly, each customer is given a unique ID that allows access the wallet, save and reuse payment methods.

### ◼️ Wallet
It is a digital wallet that allows the customer to speed up the purchase flow and not have to enter their payment method data each time. If enabled from the Dashboard, the customer is given the option of charging his wallet, and use that credit for subsequent purchases.

The wallet allows reloading of amounts from vouchers. Therefore, your credit can only be used for the purchase of products that can be purchased with vouchers.

See [here](resources/payment-gateways#wallet) for more details.

### ◼️ Payment
It is the entity that enables a customer to make a payment. It must be created via api each time the user intends to make a payment. A session is generated on the Voucherly server to which the user is redirected to allow him to choose the payment gateways and finalise the process.

A payment consists of several transactions, each identifying the payment attempt at a certain payment gateway.

See Use Cases section to better understand how to use it.

### ◼️ Payment Gateway
It's the external service that Voucherly relies on to authorise and process transactions.

The payment gateways can be activated and deactivated from the Dashboard after entering the keys obtained by direct agreement between the individual gateway and the merchant.

See [here](resources/payment-gateways) for more details.

### ◼️ Payment Method
A payment method is the instrument used by the customer in a payment gateway to carry out a transaction in a payment.

In Voucherly each customer is saved and assigned a unique id. During a transaction, the customer can select the option to save their payment method if the payment gateway allows it.
