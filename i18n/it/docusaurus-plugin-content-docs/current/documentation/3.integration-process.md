# Processo di integrazione

Segui questi passaggi per configurare l'ambiente e iniziare ad accettare pagamenti con Voucherly.

## Passaggi di configurazione

### 1. Creazione dell'account
Accedi alla Dashboard e registra un nuovo account.  
Verifica il tuo indirizzo email cliccando sul link inviato alla tua casella di posta.

Successivamente, vai su **Configurazione merchant > Panoramica** e inserisci i dati del merchant.

:::warning
È necessario completare i dati di fatturazione del merchant e aggiungere un metodo di pagamento, che verrà utilizzato per il pagamento dell'abbonamento. Una volta verificati i dati, l'account sarà attivato rapidamente.
:::

### 2. Ottenere le API Key
Nella sezione **Sviluppatori** della Dashboard, troverai sia la chiave privata che quella pubblica.  
Utilizza la chiave privata per autenticare le chiamate API, come spiegato in [Autenticazione API](/api/authentication).  

La chiave pubblica è destinata alle chiamate API dal frontend, consentendo solo la creazione di pagamenti.

### 3. Abilitare i Gateway di Pagamento
Attiva i gateway di pagamento in **Configurazione merchant > Gateway di pagamento** sulla [Dashboard](https://dashboard.voucherly.it/).

Spesso i pagamenti con buoni devono essere integrati con una transazione standard (ad esempio, un pagamento con carta). Per questo motivo, è obbligatorio attivare almeno un gateway di pagamento non legato ai buoni pasto.

:::warning
La maggior parte dei gateway di pagamento richiede parametri di configurazione specifici del merchant per l'attivazione. Questi parametri devono essere ottenuti direttamente dal merchant attraverso un accordo con il gateway di pagamento.
:::

### 4. Configurare i Gateway di Pagamento
Per i gateway che richiedono le credenziali del merchant, assicurati che siano configurati per funzionare con i sistemi Voucherly. Consulta le [Note di Configurazione](resources/payment-gateways#configuration-guide) per ciascun gateway.

### 5. Scegliere il Miglior Abbonamento
Seleziona un piano di abbonamento che soddisfi le esigenze di pagamento del merchant.  
Puoi aggiornare o ridurre il tuo piano in qualsiasi momento per adattarlo alle tue necessità.

### 6. Personalizzare il Branding (Opzionale)
A seconda del piano di abbonamento selezionato, è possibile personalizzare lo stile della pagina di checkout.

Puoi modificare:
- Colori personalizzati
- Logo e icona personalizzati
- Dominio personalizzato
