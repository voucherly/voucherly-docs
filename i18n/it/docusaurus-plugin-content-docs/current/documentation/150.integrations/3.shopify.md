# Shopify
To integrate Voucherly on you Shopify store, enable the integration from the [Dashboard](https://dashboard.voucherly.it). 



## Configuration

1. [Create an app](https://help.shopify.com/it/manual/apps/app-types/custom-apps) from your Shopify dashboard.

2. Configure the Admin API scopes (tab "configuration" > "Admin API integration"). Select the following scopes: `write_order_edits`, `read_order_edits`, `write_orders`, `read_orders`, `read_products`.

3. Install the app to get the API access token and API secret key ("API credentials" tab).

4. [Create a custom manual payment method](https://help.shopify.com/it/manual/payments/manual-payments#crea-un-metodo-di-pagamento-manuale-personalizzato) named "Voucherly"

5. Get your Shopify store URL, in the format mydomain.myshopify.com.

6. (optional) By default, the entire amount of the order will be payable with vouchers. To limit payments via vouchers to only certain products, assign a dedicated tag (*Food Product Tag*) to them.
