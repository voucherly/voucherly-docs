# Gateway di Pagamento

## Wallet
Il Wallet è un gateway di pagamento virtuale fornito da Voucherly che consente ai clienti di caricare credito utilizzando diversi tipi di buoni. Per i pagamenti futuri, i clienti possono utilizzare il Wallet per pagare articoli alimentari senza dover interfacciarsi nuovamente con i gateway di pagamento per buoni.

Un ulteriore vantaggio del Wallet è che elimina la restrizione di utilizzare buoni pasto di valori predefiniti, offrendo maggiore flessibilità ai clienti.

:::warning
Per utilizzare il Wallet, il sito web del merchant deve gestire la memorizzazione dell'ID cliente di Voucherly, generato la prima volta che un cliente effettua un pagamento. Questo ID deve essere fornito nei pagamenti futuri.
:::

## Gateway di Pagamento Fallback
Per migliorare l'affidabilità e la disponibilità del servizio, i merchant possono configurare un gateway di pagamento fallback per ciascun gateway non-voucher tramite il Dashboard. Questo assicura che, se durante il processo viene rilevato un errore del gateway (ad esempio, una temporanea indisponibilità), gli utenti possano comunque completare il pagamento.
