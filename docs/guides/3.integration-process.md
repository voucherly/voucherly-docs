# Integration Process

Follow these steps to set up your environment and start accepting payments with Voucherly.

## Configuration Steps

### 1. Account Creation
Visit the Dashboard and register a new account.  
Verify your email address by clicking the link sent to your inbox.

Next, navigate to **Configurazione merchant > Panoramica** and input the merchant's details.

:::warning
You must complete the merchant's billing information and add a payment method, which will be used to pay the subscription. Once the data is verified, your account will be quickly activated.
:::

### 2. Obtain API Keys
In the **Sviluppatori** section of the Dashboard, you will find both private and public keys.  
Use the private key to authenticate API calls, as explained in [API Authentication](/api/authentication).  

The public key is intended for frontend API calls, allowing only payment creation.

### 3. Enable Payment Gateways
Activate payment gateways in **Configurazione merchant > Gateway di pagamento** on the [Dashboard](https://dashboard.voucherly.it/).

Often, voucher payments need to be supplemented with a standard transaction (e.g., card payment). For this reason, activating at least one non-voucher payment gateway is mandatory.

:::warning
Most payment gateways require merchant-specific configuration parameters for activation. These parameters must be obtained by the merchant directly from the payment gateway.
:::

### 4. Configure Payment Gateways
For gateways requiring merchant credentials, ensure they are configured to work with Voucherly's systems. Refer to the [Configuration Notes](resources/payment-gateways#configuration-guide) for each gateway.

### 5. Choose the Best Subscription
Select a subscription plan that meets the merchant's payment needs.  
You can upgrade or downgrade your plan anytime to suit your evolving requirements.

### 6. Customize Branding (Optional)
Depending on your subscription plan, you can customize the style of the checkout page.

You can adjust:
- Custom colors
- Custom logo and icon
- Custom domain
