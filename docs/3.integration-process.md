# Integration process
Let's start to setup the environment so you can start accepting payments.

## Configuration steps

### 1. Account creation
Go to the Dashboard and register a new account.
Before you can proceed, you will need to verify your email address by clicking on the link sent to your email address.

After that, under "Merchant" > "Overview" insert the merchant data.

:::warning
You have to fill merchant's billing data and enter a payment method, which will be used for payment of the subscription. Afterwards, once the data entered has been verified, the account will be activated quickly.
:::


### 2. Obtain Api Key
From the Dashbord, in developers section you can find private and public key. In order to authenticate your api calls, you have to use private key as explained in [API Authentication](/api/authentication). 

Public key has to be used if you intend to publish the key to make api call from the frontend. It only allows the creation of payments.

### 3. Enable Payment Gateways
Payment gateways can be activated in settings > payment gateways of the [Dashboard](https://dashboard.voucherly.it/).

Most of the time, it will also be necessary to supplement the voucher payment with a classic transaction (e.g. by card). For this reason, it is mandatory to activate at least one non-voucher payment gateway. 

:::warning{type="warning"}
For most payment gateways, you are required to enter merchant specific configuration parameters to activate it. This parameters are obtained by the merchant by direct agreement with the payment gateway.
:::

### 4. Configure payment gateways
For payment gateways for which the merchant is required to entere their credentials, the merchant must configure the payment gateways to be compatible with Voucherly systems. For each gateway, see the [configuration notes](resources/payment-gateways#configuration-guide).

### 5. Choose the best subscription 
Make sure you choose the right subscription that will allow you to satisfy all payments requests from the merchant website. You can always upgrade or downgrade your subscription plan in the future to best suit your needs.

### 6. Customize branding (optional)
Depending on the subscription plan selected, it's possible to customise the style of the checkout page. 

You may set:
- Custom colors
- Custom logo and icon
- Custom domain
