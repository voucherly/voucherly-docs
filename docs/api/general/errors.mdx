# Errori


Voucherly utilizza i codici di risposta HTTP convenzionali per indicare il successo o il fallimento di una richiesta API. In generale: i codici nell'intervallo  `2xx`  indicano un successo. I codici nell'intervallo  `4xx`  indicano un errore dovuto alle informazioni fornite (ad es. un parametro obbligatorio è stato omesso, un addebito è fallito, ecc.). I codici nell'intervallo  `5xx`  indicano un errore dei server di Voucherly (questi sono rari).

Gli errori vengono restituiti come [problem details (RFC 7807)](https://www.rfc-editor.org/rfc/rfc7807). Consulta le guide ufficiali.
