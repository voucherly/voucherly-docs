# Postman collection

Per semplificare e accelerare il processo di integrazione, forniamo una Postman collection insieme a un relativo file di environment. Queste risorse sono pensate per aiutarti a interagire con le API di Voucherly senza sforzo, seguendo le linee guida descritte nella documentazione.


## Download

- **<a target="_blank" href="/download/Voucherly_API_v1.postman_collection.json" download>Postman collection</a>**. La collection include tutti gli endpoint API necessari.
- **<a target="_blank" href="/download/Voucherly.postman_environment.json" download>File di environment</a>**. Pre-configurato con segnaposto per le variabili essenziali, come l'ApiKey.

## Passaggi
1. Scarica la Postman collection e il file di environment qui sopra.
1. Sostituisci il segnaposto ApiKey con quello disponibile nella tua Dashboard, nella sezione Sviluppatori.
1. Inizia dall'endpoint “Create payment with new customer”, che funge da punto di partenza per l'integrazione.
