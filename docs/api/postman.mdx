# Postman collection

To simplify and accelerate the integration process, we provide a Postman collection along with a corresponding environment file. These resources are designed to help you interact with Voucherly's APIs effortlessly, following the guidelines outlined in the documentation.


## Downloads

- **<a target="_blank" href="/download/Voucherly_API_v1.postman_collection.json" download>Postman Collection</a>**. The collection includes all necessary API endpoints.
- **<a target="_blank" href="/download/Voucherly.postman_environment.json" download>Environment File</a>**. Pre-configured with placeholders for essential variables, such as the ApiKey.

## Steps
1. Download the Postman collection and environment file above.
1. Replace the placeholder ApiKey with the one available in your Dashboard under the Developers section.
1. Start with the “Create payment with new customer” endpoint, which serves as the entry point for integration.
