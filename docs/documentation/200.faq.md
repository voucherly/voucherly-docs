# FAQs

A list of questions and answers that might resolve some doubts.

::callout{type=""}
#summary
**Some payment gateways are not shown to the customer on the Voucherly Checkout page.** 

#content
There could be several reasons:
- The payment gateway in question has not been enabled by the Dashboard
- The customer's payment amount is below the minimum for that payment gateway, so it is not shown.
::

::callout{type=""}
#summary
**A customer has empty wallet credit, despite having charged his wallet in a previous payment.** 

#content
- Make sure you save the Voucherly Customer ID associated with each user at the end of a payment.
- When creating a payment be sure to send Voucherly Customer ID.
::

::callout{type=""}
#summary
**A customer cannot make a transaction with Wallet, even if he has sufficient credit remaining.** 

#content
- Wallet contains voucher credit, so it can only be used for food items (`IsFood` to true).
::

::callout{type=""}
#summary
**An error occurs when a user intends to use a certain payment gateway.** 

#content
- Make sure you have configured your payment gateway correctly (see [here](resources/payment-gateways)).
- If the problem persists, please contact us in the [contact page](https://voucherly.it/#contact).
::
