# Payment Gateway

## Wallet
It' a virtual payment gateway offered by Voucherly that allows customer to charge credit from different type of vouchers. In future payments, customer can pay food articles with wallet without having to interface with voucher payment gateways again each time.

Another advantage is that with wallet, the customer is not restricted to have to use meal vouchers of a predetermined size.

:::warning
To be able to use the wallet, the merchant's website must manage the storage of the Voucherly customer ID, generated the first time a new customer make a payment. In the future payments, it has to be passed to Voucherly.
:::

## Fallback payment gateway
In order to increase the reliability and availability of the service, for each non voucher payment gateway it's possible to configure one as fallback throw the Dashboard. In such a way that if a payment gateway error is detected during the process (e.g. temporary unavilability of the gateway), the user will be always able to complete the payment.
